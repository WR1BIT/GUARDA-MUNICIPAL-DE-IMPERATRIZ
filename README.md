# Missão Aprovação — Agente Municipal de Trânsito

App de estudo gamificado para o concurso de Agente Municipal de Trânsito de Imperatriz–MA.

## Usar

Abra `index.html` em um navegador moderno. Não é necessário instalar dependências. O progresso fica salvo no navegador; a cópia opcional no Supabase exige autenticação e é iniciada manualmente.

## Inclui

- Trilha sugerida de 12 semanas com rotina diária das 20h às 21h.
- Missões curtas, sessão 10–20–20–10, XP, níveis e conquistas.
- Feedback imediato, revisões espaçadas 1–3–7 e painel de evolução.
- Simulado autoral de 20 questões nos pesos históricos 10/5/3/2 do concurso de 2019.

A meta de 85% é pessoal. O simulado e os pesos históricos não representam um edital futuro. Consulte [LEIA-ME_app.md](LEIA-ME_app.md) para detalhes de uso, conteúdo e persistência.
